# School Talk

En statisk webbplats för att träna engelska som används i skolan: dialoger, rollspel, fraser, övningar och ord. Allt läses upp med webbläsarens brittiska röst (Web Speech API), kan spelas långsamt och har svensk översättning som går att dölja.

## Publicera med GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, mapp: `/ (root)`.

## Ändra innehåll

Allt innehåll (teman, dialoger, fraser och ordlistor) finns i `js/data.js`.
